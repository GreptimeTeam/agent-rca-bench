# Release artifacts

Files under `artifacts/` contain sanitized benchmark results. They exclude provider payloads,
source telemetry rows, label files, source archives, credentials, and local machine paths.

The repository's Apache-2.0 license covers the exporter, artifact schema, and benchmark metadata.
It does not replace the source dataset license. Aegis aggregate facts cite the source dataset
record's CC-BY-4.0 declaration. The reviewer artifact's root Apache-2.0 file does not explicitly
cover `reproduction/data`, so reproduce the aggregates through the pinned downloader instead of
redistributing source telemetry.

OpenRCA2's dataset card declares Apache-2.0 while its paper says CC-BY-SA-4.0 and does not link the
anonymized artifact as the promised archival release. The v32 artifacts therefore publish only
derived audit facts and hashes; reproduction downloads the pinned source without redistributing
telemetry.

Development artifacts preserve negative or prompt-informing pilot results. Measurement artifacts
require a complete frozen formal schedule and deterministic rescoring. Multi-model measurement
summaries keep treatment comparisons within each model; they do not pool correctness across
providers or models.

Protocol v31 outputs are retained as historical development records:

- `measurement/semantic-rca-v31-micro.json`: 192 sanitized Discovery and Graph cells with cited
  canonical aggregates and deterministic public rescoring.
- `measurement/aegis-transfer-v31-six-model.json`: 24 sanitized end-to-end cells with structured
  diagnosis, citation grounding, reliability, usage, and model summaries.
- `measurement/semantic-rca-v31-report.json`: combined 216-cell report derived only from the two
  sanitized artifacts.
- `measurement/semantic-rca-v31-report.html`: self-contained rendering of the combined report.
- `measurement/semantic-rca-v31-analysis.md` and `.zh-CN.md`: English and Chinese interpretation
  with the applicability and release-boundary limits kept explicit.
- `measurement/semantic-rca-v31-SHA256SUMS`: hashes for the six v31 report and analysis files.

The current runtime does not load, rescore, resume, export, or render those internal v31 records.
Use the corresponding historical Git revision when inspecting them.
