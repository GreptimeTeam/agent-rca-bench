What the experiment says

Relationship retrieval

The relationship query surface reduced calls and rows for every model with eligible paired cases; one model had no eligible Graph pair.

Table discovery

Discovery effects vary by model and metric; the semantic interface is not a uniform efficiency win for table localization.

End-to-end RCA

All models found the causal component and mechanism, but required evidence was covered in only one unpaired Graph run; no end-to-end efficiency effect can be estimated.

Correctness is a qualification gate, not a claimed product effect. Descriptive totals: micro success Raw 89, Graph 85; transfer diagnosis correctness Raw 12, Graph 12.

Limits on interpretation

  • The eight-case micro cohort is a fixed reference cohort, not a fresh population holdout.
  • The end-to-end transfer result contains one independent Aegis case; it cannot estimate a broad population effect.
  • No transfer treatment pair covered all required evidence, so end-to-end efficiency deltas are not estimable.
  • Provider reasoning settings are frozen configurations, not a common compute scale.
  • Costs are provider-price estimates in original currencies; missing prices remain unavailable and currencies are not converted.
  • Claude prompt caching was enabled, but provider usage reported no cache creation or reads for the micro-benchmark cells; the longer transfer cells did report cache usage. Costs use the reported usage without imputing hits.
  • This execution did not bind the benchmark worktree to a Git commit; a tagged public release requires a clean, commit-bound rerun.
